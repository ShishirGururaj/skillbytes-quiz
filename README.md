# SkillBytes Quiz Application

A WhatsApp-style quiz application built with React, FastAPI, and MongoDB.

## Architecture

- Frontend: React
- Backend: FastAPI
- Database: MongoDB
- Analytics: MongoDB aggregation pipelines

## Application Flow

Login → Exam → Subject → Chapter → Quiz → Result

## Development

Backend setup and frontend setup instructions will be added as implementation progresses.

## Analytics

The application will capture question-level attempt events and use them as the source of truth for:

1. Learning Velocity Index
2. Fatigue Analysis
3. Question Difficulty Index
